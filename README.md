# Easy Billing: Releases

This repository holds the official Windows installers and update files for **Easy Billing**, an offline GST billing and invoicing app for small shops.

The app's source code is not here. This repo only carries finished releases.

## Download

1. Open the [Releases](../../releases) page.
2. Under the newest version, download `EasyBilling-Setup-<version>.exe`.
3. Run it and follow the steps. No admin rights are needed.

You need a licence key to use Easy Billing after the free trial. Contact the person who supplied the app to get one.

## Updates

Installed copies of Easy Billing look for new versions here when you allow it, under **Settings → Updates**.

- Easy Billing **never updates on its own**. A new version is downloaded and installed only when you click the buttons.
- Your data is backed up before an update is installed.
- You can keep using your current version for as long as you like.

## Windows security warning

Windows may show a "Windows protected your PC" screen the first time you run the installer. Click **More info**, then **Run anyway**. This appears because the installer is not yet code-signed.

## Your data

Your invoices and customers stay on your own computer. Uninstalling Easy Billing does not delete them.

## Support

For help or a licence key, contact the person who supplied Easy Billing to you.
